ShortGen

ShortGen is a video preparation and publishing tool operated by Beathill Racing. It turns source footage into platform-ready videos and lets an authorized user choose where each finished video is published.

Get it on Google Play

Publishing workflow

  • The user uploads or prepares a video inside ShortGen.
  • The user reviews the rendered video, thumbnail, caption and language.
  • The user explicitly selects YouTube, Instagram, Facebook or TikTok.
  • ShortGen publishes only after the user presses the publish button.

TikTok integration

ShortGen uses TikTok Login Kit and the Content Posting API. Draft upload sends a selected video to the authorized TikTok account for review in TikTok. Direct posting is used only when TikTok grants the required permission and the user explicitly selects it.

Account control

Users authorize their own platform accounts through OAuth and can revoke access through the relevant platform settings. ShortGen does not ask users to provide their social-media passwords.
